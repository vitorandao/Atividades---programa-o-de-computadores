# <div align="center"> Atividades - Programação de Computadores</div>

Repositório destinado ao registro das **atividades práticas desenvolvidas em sala de aula** na disciplina de Programação de Computadores, com foco no desenvolvimento da **lógica de programação e dos fundamentos da linguagem Python**.

Os exercícios presentes neste repositório acompanham a evolução dos conteúdos estudados, desde conceitos fundamentais até estruturas e práticas essenciais para a construção de programas.

##  Conteúdos estudados

### 1. Fundamentos da programação

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores aritméticos, relacionais e lógicos
* Estrutura básica de programas em Python

### 2. Controle de fluxo e raciocínio lógico

* `if`, `elif` e `else`
* Estruturas de repetição com `while` e `for`
* Desenvolvimento do raciocínio lógico
* Resolução de problemas por meio de algoritmos

### 3. Estruturas de dados básicas em Python

* Listas
* Tuplas
* Estruturas lineares
* Manipulação e organização de dados

### 4. Escopo, funções e boas práticas

* Criação e utilização de funções
* Escopo de variáveis
* Organização do código
* Boas práticas de programação
* Identificação e correção de erros (depuração)

##  Objetivo

O objetivo deste repositório é **documentar a evolução no aprendizado de programação**, reunindo exercícios realizados durante as aulas e servindo como material de consulta para reforçar os conceitos fundamentais de Python e lógica de programação.

##  Tecnologias

* **Python**
* **VS Code**
* **Git e GitHub**

##  Organização

Os arquivos estão organizados de acordo com os conteúdos e atividades desenvolvidos ao longo das aulas, permitindo acompanhar progressivamente os conceitos trabalhados.
